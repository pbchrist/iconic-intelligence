# Done means

A change is done only when all of these are true, and someone other than the builder checked them:

1. The page opens locally with no console errors, at desktop and phone widths, and in-page links land where they should.
2. `CHANGELOG.md` has one line saying what changed and why.
3. It is one PR, Patrick said yes, and the PR says what was checked and how.
4. After merge (which publishes): iconic.onl shows the change. If it is a release, it gets a `live-YYYY-MM-DD` tag.
