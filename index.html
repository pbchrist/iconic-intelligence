How it works

It learns one business, and it keeps the record.

01

The record

The market is written down every day. The history stays on hardware I run. The longer it runs, the more of that market it holds.

02

The connector

I built a private connector so Claude Code can ask this history questions and get the stored numbers back. In a test on my own hardware, a local AI answered 25 of 100 questions about what changed without the history, and 96 with it. It still got some wrong. The connector is in testing. There is no public install.

03

Last month's history

Anyone can read today's listings. Nobody can go back and read last month's. ICONIC already has them.

The history

Your market history stays on hardware I run.

I read every briefing before it goes out. Briefings are written with Claude, a cloud AI, from public listing data and the requests you give me.

Running now

One dealer is on it now.

I have one live client, a franchise dealer. I do not name clients. ICONIC is for an owner who runs the store, one rooftop or a small group.

Every morning it reads the rivals' Sierra 1500 lots: each truck, price, trim and VIN. A briefing goes out Monday, Wednesday and Friday mornings. None goes out until I approve it.

Between briefings, they can text questions to a private Telegram bot.

The number

Every number in a briefing points to the dated listing or page it came from.

The same truck

You should know when a rival undercuts a truck you both have, before you lose the deal.
