01 / THE METHOD

A live decision.
Not a vanity score.

Availability is the starting line. We test the actual choice a model makes when several tools are presented together.

  1. 01

    READ THE TOOLS

    Provide your public HTTPS MCP endpoint. We read its tools/list metadata; we never execute the tools or ask for a login.

  2. 02

    CHECK THE RIVALS

    We find reachable candidates and screen them for comparable capabilities. If fewer than three qualify, we refuse to publish a misleading comparison.

  3. 03

    MEASURE THE CHOICE

    OpenAI, Anthropic and Google model families receive plain-language tasks. Tool ordering changes each trial; we count actual tool selections and uncertainty.

  4. 04

    REWRITE. RETEST.

    You get clearer tool descriptions and a before-and-after test on held-out requests. A negative result stays negative. No invented improvement.

02 / WHAT YOU GET

A report you
can interrogate.

Results are broken down by model, with sample sizes, competing choices, description changes, and the tasks behind the numbers.

MEASUREMENT

Selection rate

Pick frequency, uncertainty interval, and model-by-model results. We also disclose when a model chooses no tool.

DIAGNOSIS

What got passed over

Candidate rivals selected instead, plus model-generated explanations. Those explanations are hypotheses, not privileged access to a model's reasoning.

RETEST

Descriptions that earn their place

Specific, truthful rewrites evaluated against held-out requests. The report shows whether selection improved or declined.

What this does not measure: organic ChatGPT recommendations, directory ranking, installs, real user traffic, or real-world adoption. Rivals are screened by models, not independently certified as interchangeable.
