How to connect an AI agent

  1. Discover: read the relevant service page, manifest, and public tool descriptions.
  2. Connect: configure the remote MCP URL in a client that supports remote MCP tools; connection and any permissions depend on that client.
  3. Test: use only fictional or nonconfidential data with the public demo and preflight tools.
  4. Authorize: any real customer data, production action, paid scope, or charge requires a separate, explicit approval path.

An MCP Registry listing helps clients find server metadata; it does not make tools automatically callable by every model. The user or platform must connect and authorize them.
