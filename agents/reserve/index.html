Agent workflow · Real calls to the live service
  1. Connect to the MCP URL below. Call reserve_describe for capabilities and the currently available free offer.
  2. Call reserve_sandbox_start. The service returns credentials for a private, one-hour fictional test tenant.
  3. Use reserve_sandbox_remember, reserve_sandbox_record_decision, reserve_sandbox_record_action, and reserve_sandbox_record_outcome to create your own synthetic case.
  4. Call reserve_sandbox_recall, reserve_sandbox_trace, and reserve_sandbox_evaluate. See which records support each conclusion, which outcomes are unverified, and what changed from baseline.
  5. Call reserve_assess for a free, structured fit assessment the agent can pass to its human. It can return NOT_A_FIT.

The sandbox uses the actual Reserve engine, not a canned script. Its records are fictional and disposable. The sandbox's separate reviewer role is simulated, not independent verification of a real business result.
